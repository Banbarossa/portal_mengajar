Cara Embed ke Google Sites

Anda dapat menyematkan modul Flip Book interaktif ini langsung ke dalam halaman Google Sites Anda dengan dua cara mudah:

Cara 1: Menyematkan Kode HTML Langsung (Paling Praktis)

  1. Buka editor Google Sites Anda.
  2. Pada panel kanan, klik menu Sisipkan (Insert) → pilih Sematkan (Embed).
  3. Pilih tab Sematkan Kode (Embed Code).
  4. Salin seluruh kode HTML file ini, tempelkan ke kotak tersebut, lalu klik Berikutnya → Sisipkan.
  5. Tarik sudut bingkai di Google Sites agar lebarnya penuh (full-width).

Cara 2: Menggunakan Tautan Hosting (GitHub Pages / Netlify / Drive)

Jika file ini sudah diunggah secara online, cukup pilih tab Dengan URL (By URL) di menu Sematkan Google Sites dan tempelkan tautannya.

Kode berhasil disalin ke clipboard!
